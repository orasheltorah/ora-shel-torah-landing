# Ora Shel Torah — Déploiement Netlify + Stripe (pas-à-pas)

1) Place ces fichiers à la racine du site (au même niveau que index.html) :
   - netlify.toml
   - package.json
   - netlify/functions/create-checkout.js
2) Ensuite, on connectera ton projet à Netlify et on ajoutera ta clé STRIPE_SECRET_KEY.
